# 智能录音卡设备调试工具 · 功能补全版

本项目是基于「简洁交互版」增加旧版设备调试能力的**纯前端可交互原型**。

## 运行方法

- **最快**：打开文件 `智能录音卡-功能补全版-单文件预览.html`（此文件在项目目录的上一级）。
- **源码模式**：在当前目录打开 `index.html`，也可以用 `python3 -m http.server 8080` 启动，在浏览器访问 `http://localhost:8080`。
- 无 Node.js、npm、网络请求或第三方依赖要求。

## 界面保持

- 蓝牙设备信息在右上角小图标浮窗，不再占用页面高度。
- 六个 Tab：设备信息 / 录音 / 固件升级 / Wi-Fi / 文件管理 / 更多。
- 「更多」只包含休眠；「高级调试」独立放在首页与设备信息页。
- 底部调试日志常驻，可以拉动顶端横杠调整高度；内部独立滚动。
- 操作无 Toast；Tab 选中为细紫色下划线；状态按钮为淡紫选中样式。

## 新增能力与模拟交互

| 模块 | 新增操作 |
| --- | --- |
| 设备信息 | 电量、SN、存储、设备状态查询；设备时间查询与同步 |
| 录音 | 录音同步查询、开启、关闭；获取 MARK 与记录列表 |
| 文件管理 | 自动分页加载（不暴露底层查询参数）、清空文件、模拟下载任务、取消、断点续传、已下载记录、本地音频数据查看 |
| 固件升级 | 升级中断保留断点，支持断点升级 |
| Wi-Fi | Wi-Fi 测试及结果状态 |
| 高级调试 | 查询配对、恢复出厂、U 盘模式查询/开启/关闭、二代音频文件查询、音频帧传输/取消、0x00/0x01 调试命令 |

保留既有功能：扫描/连接蓝牙设备、设备详情、录音、MARK 开关与锁定、OTA 开关/本地/线上固件、Wi-Fi 开关/连接、休眠时间、日志复制和清空。

**重要：** 蓝牙、Wi-Fi、固件升级、音频流和文件内容均为浏览器本地的模拟数据。点击下载文件不会从硬件传输音频；“已下载文件”记录不含真实媒体字节；OTA 升级不会对硬件写入固件。真实设备接入需用硬件协议/SDK 替换 `app.js` 内的模拟实现，并在设备回执后更新 UI 状态。

## 回归检查

`test_features.py`：使用 Chromium Playwright 检查 320/375/390/425 宽度下的核心流程，包含状态变化、文件传输与续传、OTA 断点升级、U 盘与工厂重置、可调日志面板和控制台错误。
